# Arrival windows and road-preview timing

Office roles can save a paired same-day arrival window and planned service duration on unstarted service. Windows use the company timezone and must end after they start; overnight windows are unsupported. A window can be removed by clearing both times. Duration ranges from zero to 720 minutes. A current version and reason are required. A change creates audit evidence and a customer notice without changing prices. Started/completed work cannot be rewritten. Driver web/native views retain the saved local window and planned work time, including cached work.

Amazon road previews now use optional per-leg `VehicleLegDetails.Summary.Overview.Duration` values from the independently inspected Geo Routes model. Durations must be finite, nonnegative, have one value for each segment and reconcile with the route summary. There is no invented equal split of total driving time. A preview lacking segment timing can still show untimed basic geometry, but a route with saved windows or service duration requires the real segment durations.

The schedule propagates segment driving, waits for each earliest arrival, adds saved service duration and shows estimated arrival/start/departure for each stop plus depot return. A planned service start after its saved window end rejects the preview without changing the saved route. A proposed optimized order is checked after provider sequencing; infeasible windows are not silently ignored. Ambiguous/nonexistent daylight-saving window endpoints require review rather than guessed local times. Window edits and company-timezone changes invalidate application of an earlier preview.

Window bounds constrain planned service **start**, not completion. Per-leg driving estimates are captured for the preview's original provider departure; traffic is not recalculated after each wait/service, and breaks, facility queues and unrecorded delays are not included. The timing table is an office planning estimate, not real-time GPS ETA, a guaranteed customer appointment or legal truck navigation. No live provider calls have been verified in this environment. Installed/device and real-provider acceptance remain required.

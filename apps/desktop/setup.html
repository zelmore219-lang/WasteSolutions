Local testing only

Use test customer information. Payments, QuickBooks, email/text delivery and live road planning are disabled. Your test work is stored locally and survives Stop/Start. Keep the local-test/.state folder with this kit. Closing the windows does not stop the containers; use Stop local services before closing when you are finished.

Before you test

This client connects to a running CoreWaste system. It does not include the database or server. A configured test server and a provisioned test account are required to sign in and test business workflows.

Server setup and Firebase activation are still pending. If you have not received a test server address, keep this installer for the next testing step.

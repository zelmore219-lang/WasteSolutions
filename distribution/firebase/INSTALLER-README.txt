COREWASTE WINDOWS INSTALLER 0.3.0 — WINDOWS 10/11 x64

1. Run CoreWaste-Setup-0.3.0-x64.exe.
2. Choose an empty installation folder. The default is your local Programs folder.
3. Open CoreWaste from the Windows Start menu.
4. The address https://wastesoloutions.web.app/office is filled in.
5. Choose Connect after the Firebase/API/database services are activated.

No Docker, Node.js or administrator account is required on your computer.
Use Windows Settings > Apps > Installed apps > CoreWaste to uninstall, or use
Uninstall CoreWaste in the Start menu. Saved AppData settings and cloud records
are preserved. Close CoreWaste before uninstalling. To reinstall, uninstall the
previous installation first; this build refuses to overwrite a nonempty folder.

The owner plans to enable billing later. Installing this client does not create

This development installer is unsigned and was compiled on Linux. Actual Windows
installation, launch and removal have not been verified. Do not disable Windows
